# Flutter Vault

Repositorio contenedor para los proyectos Flutter del vault.

Cada carpeta de app se guarda como submodulo para mantener su historia Git independiente.

## Compatibilidad Android

No subir el `minSdkVersion` por encima de 21 en los proyectos Flutter de este vault.

Muchas decisiones de estos proyectos se hacen especificamente para mantener compatibilidad con Android 21 en adelante y cubrir dispositivos viejos. Las advertencias de Flutter o Gradle sobre subir el minimo a 23 no deben aplicarse automaticamente; solo se cambia si el dueno del proyecto lo pide explicitamente.
