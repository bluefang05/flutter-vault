# Instrucción para Codex

1. Ejecuta `tool/bootstrap_windows.ps1` si falta la carpeta `android`.
2. Ejecuta `flutter pub get`, `flutter analyze` y `flutter test`.
3. Corrige únicamente errores reales de compilación o cambios de API entre la versión instalada de Flutter/Flame y las dependencias fijadas.
4. No elimines ninguno de los seis poderes.
5. Mantén el banner arriba y fuera del área del juego.
6. No introduzcas intersticiales ni videos obligatorios.
7. No sustituyas los assets provisionales hasta recibir los definitivos.
8. Conserva el nombre visible `NBND` y el identificador sugerido `com.enmanuelapp.nbnd`.
9. Si se exige API 21, no eleves silenciosamente el minSdk: informa qué versión de Flutter y plugins se fijarán y qué funciones dejan de estar soportadas.

10. Conserva la barra de cucharas: cada unidad visual equivale a dos medias cucharas.
11. Los valores de reserva por perfil son balance provisional; no los presentes como clasificación clínica.
12. Si reemplazas los PNG, mantén las rutas de `assets/images/spoons/` o actualiza `SpoonLifeBar`.
